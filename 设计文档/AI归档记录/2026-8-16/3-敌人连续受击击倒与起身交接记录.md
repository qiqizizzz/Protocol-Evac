## 二、本次确认的根因

原敌人受击配置引用 `Rig|Hit_Chest`，实际时长只有 `0.333s`。此前即使提高 `MinimumHurtDurationValue`，视觉动作仍会立刻结束。

更重要的运行态根因是 `EnemyAnimWriter.Tick()`：受击请求消费后，下一帧会因 `Movement.IsMoving` 变化调用 `PlayLocomotion()`，直接将一次性受击、击倒或起身 Clip 覆盖为 Idle / Walk。因此硬直时间存在，但动画表现没有保持。

修复边界：

```text
EnemyAnimWriter.Tick
└─ EnemyActionContext.IsHurt 为 true
   └─ 禁止待机 / 移动动画切换覆盖当前一次性受击动画
```

不要通过重复循环短受击 Clip 来伪造硬直，也不要让行为树在受击期间驱动动画。

## 三、当前受击链路

敌人动画配置位于：

```text
Assets/Config/Enemy/Animation/Enemy_流浪者AnimationConfig.asset
```

当前配置：

```text
首段受击：Rig|Hit_Chest       0.333s
击倒动画：Armature|Hit_Knockback 0.833s
起身动画：Armature|LayToIdle     1.533s
连续命中判定间隔：1.2s
触发击倒所需命中次数：2
最短受击硬直：0.8s
```

运行链路：

```text
CombatHitbox
└─ DamageData
   └─ EnemyDamageReceiver
      └─ EnemyController.HandleDamageReceived
         ├─ EnemyDamageController 记录连续命中次数
         ├─ 第 1 次：短受击 + 命中位移
         └─ 第 2 次及后续：击倒 + 命中位移

击倒硬直结束
└─ EnemyDamageController.ConsumeGetUpRequest
   ├─ EnemyDamageContext.BeginHurt(起身动画时长)
   └─ EnemyActionContext.BeginGetUp
      └─ EnemyAnimWriter 播放 LayToIdle
         └─ 起身结束后 EnemyActionContext.FinishHurt
            └─ BT / 技能 / 导航恢复执行
```

`EnemyDamageController` 不再因为 `EnemyDamageContext.IsHurt` 拒绝后续命中。连续普攻能够在上一击硬直中刷新为击倒表现；同一攻击窗口的目标去重仍由 `CombatHitbox` 负责。

## 五、玩家首段普攻击退

配置：

```text
Assets/Config/Player/Skill/Window/Attack/Chisaki_attack01_begin_WindowConfig.asset
```

首段命中窗口参数已从：

```text
速度 2.5，持续 0.2 秒，理论位移 0.5 单位
```

调整为：

```text
速度 4.5，持续 0.35 秒，理论位移 1.575 单位
```

实际位移仍由 `EnemyMotor` 和 `CharacterController` 执行，遇到场景碰撞会自然缩短，不能用动画根运动补偿。

## 六、MCP 运行态验证

在 `GameScene` Play Mode 中对场景敌人注入两次间隔命中，观察到：

```text
0.43s：hurt=True，remaining=0.62，clip=Armature|Hit_Knockback
1.21s：hurt=True，remaining=1.38，clip=Armature|LayToIdle
2.91s：hurt=False，remaining=0.00，clip=Rig|Walk_Loop
```

这证明击倒期间没有被移动动画覆盖，起身期间仍锁定 AI，结束后才恢复移动。测试已退出 Play Mode，场景状态未保存。

## 七、后续验收重点

```text
1. 实机连续普攻：确认首段短受击、第二段击倒、起身节奏符合手感
2. 起身期间再次命中：确认新命中正确中断起身并刷新受击表现
3. 击倒贴墙：确认 CharacterController 阻挡时不会穿模或卡住
4. 调整首段击退：以 4.5 x 0.35 为基线，只改第一段命中窗口数据
```

若需要区分不同攻击的击倒阈值，应优先在 `DamageData` 或 Ability 命中窗口增加显式受击等级；不要在 `EnemyController` 按伤害数值猜测。
